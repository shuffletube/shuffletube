Frequently Asked Questions

How do I get a YouTube API key?

Getting a free YouTube API key:

1. Go to Google Cloud Console.
2. At the top-left of the screen, click Select Project, then click New Project on the top right of the pop-up window.
3. Name the project and wait for it to be created. Afterwards, select the project.
4. Inside the project, use the search bar at the top and search for YouTube Data API v3. Open it and click Enable.
5. Open the navigation shelf on the left and go to Credentials → + Create Credentials → API Key.
6. In the API key settings, enable API restrictions, choose YouTube Data API v3, and create the key.
7. Copy the key and paste it into the field in Advanced Mode.

Google's free tier allows ~200 API calls a day (per Gmail account). Limit resets at midnight PST.

What does the main button do?

It finds an unusual YouTube video for you. Depending on your Advanced settings, ShuffleTube can use a direct discovery search, a normal YouTube search, or occasionally surface a curated discovery from its collection.

What is API Discovery?

ShuffleTube generates a random search pattern, asks YouTube for a batch of results, filters out things you have already received, and opens one result automatically.

What is Search String?

ShuffleTube generates the search phrase for you and opens the normal YouTube results page. You can then explore the results yourself.

Can I see the same video again?

The browser remembers previously delivered video IDs locally and tries not to give the same one to you again during discovery.

What does Advanced Mode change?

It changes how the main ShuffleTube button searches: discovery method, media family, view-count preference, and age preference.

Does the room change?

Yes. The room is generated from a randomized combination of textures, lighting, posters, objects, and proportions.

THE TECHNOLOGY

How the search works

01 — These are file names, not magic words

The search engine works with the kinds of names cameras, phones, screen recorders and editing software create automatically. A phrase such as IMG 4827 or GOPR1847 can look ordinary, but it can also lead to videos that are very unlikely to be found through a normal recommendation feed.

IMG 4827 MVI 0039 DSCF7281 GOPR1847 PXL 20210314

02 — What is a “Family”?

Family is a group of related naming habits. Instead of choosing one camera pattern manually, the generator can choose from an entire family of patterns.

PHONEIMG {n4}PXL {n4}VID {date}
CAMERADSC {n4}DSCF{n4}DSCN{n4}MVI {n4}
ACTION CAMGOPR{n4}GP01{n4}GX01{n4}
SCREEN / EDITORCapture {date}Screen Recording {date}Untitled Project

03 — The little tokens create the randomness

Parts wrapped in braces are generators. {n4} becomes a random four-digit number, {n3} a three-digit number, and {date} becomes a randomized date.

GOPR{n4}template
→
GOPR4827generated code
→
"GOPR4827"YouTube query

04 — The map can add search operators too

A template can contain more than a file name. For example, the same family can carry a time boundary or another search condition.

GOPR{n4} before:2008 IMG {n4} before:2015 MVI {n4} before:2012 WIN YYYYMMDD

05 — Empty results are part of the process

A generated code can simply lead nowhere. That is expected. When a query returns no useful videos, API Discovery silently throws that code away and generates another one.

DSCI5589× 0 results DSCF2741× 0 results IMG 4837found

06 — Why the search can keep changing

The same map can produce thousands of combinations because one family can contain many templates, numbers, dates and optional search conditions. The machine keeps choosing a new path until it finds something worth opening.

The room keeps moving underneath this screen—it's only dimmed so the "inside the machine" feeling remains visible. Every code floating around you is real. These are the actual naming patterns and search structures the generator uses to find videos.
